How to Report a Potential Vulnerability?
========================================

If you would like to report a public issue, please report it as a
[GitHub issue](../../issues/new). If you have a patch ready, submit it following
the same procedure as any other patch as described in [CONTRIBUTING.md](CONTRIBUTING.md).

For a not-yet released or urgent issue, please contact the
[Product Security team](mailto:product-security@qualcomm.com) or see the
[Report a Bug](https://www.qualcomm.com/company/product-security/report-a-bug)
page.

Security reports for this repository should include as much of the following as possible:

- Description of the vulnerability.
- Steps to reproduce, including MATLAB release, operating system, and 5G Toolbox availability.
- Whether the issue affects MATLAB scripts, packaged MEX binaries, MEX C++ sources, or generated output files.
- Affected versions, branches, or source snapshots.
- Potential impact.
- Any relevant logs, stack traces, crash reports, screenshots, or generated files.

## Coordinated Disclosure

We follow a Coordinated Vulnerability Disclosure (CVD) process:

- **Initial Response**: We will acknowledge your report within 48 hours.
- **Investigation**: Our team will investigate the issue and provide updates.
- **Resolution**: We will work with you to resolve the issue and prepare a fix.
- **Disclosure**: Once the fix is ready, we will disclose the vulnerability and notify affected users.
